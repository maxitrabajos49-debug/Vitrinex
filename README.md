🌐 Proyecto VITRINEX
Vitrinex es el inicio de un proyecto personal desarrollado por Jaime Herrera y Maximiliano Inostroza, enfocado en crear una plataforma digital para emprendedores chilenos.
Su propósito es ayudar a los usuarios a mostrar, gestionar y potenciar sus negocios mediante una herramienta moderna, intuitiva y accesible.

---

🚀 Etapa actual del desarrollo
Este repositorio representa los primeros pasos del proyecto, donde se ha comenzado con:

Configuración del entorno de desarrollo con Node.js, Express y MongoDB Atlas.
Implementación del control de versiones con Git y GitHub.
Instalación de dependencias base y pruebas de commits iniciales.
Preparación de la estructura para futuras integraciones del backend.

---
